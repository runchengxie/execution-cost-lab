## 一笔交易到底花了多少钱

先固定决策参考价，再拆三笔账。**直接费用**来自佣金、税费及其他收费。**成交价差**是已成交部分相对参考价的有方向价差。**机会成本**是在共同截止时刻，给没成交的部分估算得失。

令买入方向为 +1、卖出为 −1。对于一笔订单，成交量为 q，计划量为 Q，成交均价为 P，参考价为 B，终点估值价为 T。实施缺口可以写为 `直接费用 + 方向 × q × (P − B) + 方向 × (Q − q) × (T − B)`。多笔成交也可逐笔计算价差再加总。组合里先按金额求和，再用一致的参考名义金额换算基点。

| 项目 | 合成买单 | 合成卖单 |
| --- | ---: | ---: |
| 计划量 / 成交量 | 1,000 / 700 股 | 1,000 / 700 股 |
| 参考价 / 均价 / 终点价 | 20.00 / 20.02 / 20.05 元 | 20.00 / 20.02 / 20.05 元 |
| 直接费用 | 8 元 | 8 元 |
| 成交价差 | +14 元 | −14 元 |
| 未成交机会成本 | +15 元 | −15 元 |
| 实施缺口合计 | **+37 元** | **−21 元** |

负数表示相对参考价有利。卖单尚未卖出的股票在终点升值，因此按这个口径产生负的机会成本。实际复核直接费用时，逐笔对齐成交额、费率和计费规则，记录最低收费、舍入和费项组成。只有合并费率的模拟交割单，最多能复核该模拟口径的算术。

## 为什么多等一会儿，数字反而更贵

把三件事分开看。第一是**每股的成交代价**，第二是**总共做了多少股**，第三是**剩下的股票后来涨跌了多少**。拉长时间可能让单次下单更小，同时把订单暴露在更长的价格变化中。两个影响可以同时发生。

| 同一笔 10,000 股合成买单 | 快速路线 | 延长路线 |
| --- | ---: | ---: |
| 实际成交量 | 6,000 股 | 8,800 股 |
| 全量手续费和成交价差 | 204.00 元 | 246.40 元 |
| 全量机会成本 | 144.00 元 | 43.20 元 |
| 总成本 | 348.00 元 | 289.60 元 |
| 都比较 6,000 股时的手续费和价差 | 204.00 元 | 168.00 元 |

这里用了首页同一套合成参数。只看全量已成交费用，容易把多做的 2,800 股当作单位成本上升。只看同量比较，又会漏掉两条路线在未成交量上的差别。实证比较时，应保留各条路线的真实成交顺序，再截到共同股数和共同参考价。自身冲击还需要单独建模，成交价与参考价的差包含市场本身的上涨和下跌。

## 开盘后第 30 秒和第 60 秒怎么比

把集合竞价和连续竞价分开。集合竞价的成交打印量只能描述市场撮合规模。估计新增委托能拿到多少，需要知道它何时进入队列、限价和撮合分配条件。连续竞价则可对照开盘即做、等 30 秒、等 60 秒。

| 对照 | 固定什么 | 回答什么 |
| --- | --- | --- |
| 相同截止时刻 | 例如全部在 09:35 停止 | 午前计划的截止时刻固定，等待值不值 |
| 相同执行时长 | 每条路线均可执行五分钟 | 多给晚启动的路线相同时长后，开盘最初一分钟还有多少价值 |
| 条件等待与撤单追价 | 同一原始需求、截止和终点估值 | 点差或可见深度满足条件再做，是否改善成交与成本 |

用报价触发等待时，规则只能看到当时已收到的行情。记录未触发的订单和超时行为。被动单还要考虑前方队列，盘口碰到限价只说明市场曾到该价位。分开报告完成率、同量成本和未成交机会成本，才能看清等待究竟节省了什么，又错过了什么。

## 从盘口容量走到组合容量

最简单的容量代理是把窗口内观察到的市场成交量乘以参与率。首页的合成例子里，前五分钟 52,000 股乘 5%，得到 2,600 股额度。把订单从 4,000 股放大到 10,000 股，这部分容量对应的完成率从 65% 降到 26%。真实回放还要逐时点检查限价、可见深度和成交额度，不能在窗口开始时就把将来的成交量当作可用额度。

周转放大后，每档都用相同的需求结构和执行规则。分别报告买入、卖出、共同达标的天数和结束时的持仓缺口。组合完成率的分子、分母都用同一组价格加权。缩单时额外保留**原计划完成率**，例如原计划 10,000 股、缩后 8,000 股、做成 7,600 股，缩后完成率是 95%，原计划只做成 76%。

检查点可比较三条路线。固定较早截止、未达标才延期、固定较晚截止。把门槛同时用在买卖两侧，可以发现总完成率掩盖的单侧问题。选规模时还要核对现金、库存和未完成仓位。两天平均值相同，可能分别来自每日稳定和某一天集中失手。

## 共享现金、库存和分配顺序

每次卖出后同时更新账面现金、可用现金和待释放回款。每次买入前查可用金额，每次卖出前查可卖股数。延长窗口能等待回款，起始可卖持仓不足则需要另外处理。

| 合成账户当下只能买 600 股 | 计划量 | 固定序依次买 | 按计划比例分配 |
| --- | ---: | ---: | ---: |
| A | 400 | 400 | 133 |
| B | 600 | 200 | 200 |
| C | 800 | 0 | 267 |
| 合计 | 1,800 | 600 | 600 |
| 最大个股缺口 | | **800 股** | **533 股** |

这里用的是首页合成模型的按股分配，先向下取整，再按余数大小补齐到总额度。实际账户如果按权重控制，应将缺口先折成同一参考价的市值，再比较占账户规模的比例。现金充足时，固定顺序、比例分配和优先补最大权重缺口可以得到相同成交。要区分资金规则，测试条件里必须出现真正的现金竞争，同时保留盘口容量作为另一条上限。

## L2 怎么回放，自身冲击怎么估

按可用时间重放盘口更新、逐笔成交和账户事件。先检查时间戳、重复或缺失记录、交易阶段、买卖盘价格与数量，再明确是用快照扫可见深度、用逐笔成交推断队列消耗，还是两者结合。回放不能让同一份可见深度被多笔模拟订单重复使用。

| 参数 | 应记录的选择 |
| --- | --- |
| 时钟 | 交易所事件时刻与策略实际可用时刻，提交和撤单延迟 |
| 主动单 | 允许扫几档、价格保护、盘口深度扣减 |
| 被动单 | 前方队列、撤单归因、同价成交分配 |
| 成交预算 | 已观察成交量的回看窗口、参与率和剩余额度能否结转 |
| 自身冲击 | 按规模或参与率变化的附加情景，比较结果在哪些假设下改变 |

历史盘口回放可以研究可见流动性和执行条件。模拟委托无法改变已经发生的历史行情。要校准自身冲击，需要能配对的真实委托、成交和行情，并考虑同一时段其他市场交易与价格走势。公开的冲击情景只能说明某个假设对结果有多敏感。

## 多路线、非凸搜索和新样本

比较路线时先冻结需求、可用信息、参考价和估值终点。搜索变量可以包括开盘等待、参与率分段、撤单追价和收手门槛。整手约束、价格保护和完成门槛会让目标函数出现跳变。用有限网格或多起点搜索观察结果是否稳定，也保留开盘即做和固定窗口等容易复查的基线。

| 证据 | 能回答的问题 | 还需补什么 |
| --- | --- | --- |
| 合成算例 | 计算、资金约束和边界条件是否符合预期 | 历史行情和可交易需求 |
| 已研究日期 | 哪种机制可能解释完成缺口，参数是否敏感 | 独立日期和更有代表性的账户输入 |
| 冻结规则后的新日期 | 候选规则在未来可用数据上是否仍然有效 | 更长样本与真实成交校准 |

新样本到来前应记录纳入规则、比较路线、门槛和缺数处理。结果上同时保留成交规模、费用、带方向的价差、机会成本、未成交量和样本覆盖。只知道交易日期、模拟成交和价格时，不能从结果倒推出策略何时知道信号，也不能补出原始计划里所有没成交的委托。
